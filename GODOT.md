# You have Godot. Do this.

## 1. Get the project

```bash
git clone https://github.com/heads4281-spec/crimson-sovereign.git
```

Or download ZIP from GitHub → Code → Download ZIP.

## 2. Open it

1. Open Godot 4.
2. Import → choose the folder that contains `project.godot`.
3. Open the project.

## 3. Put the 3D files in

Create folder:
`assets/crimson_sovereign/`

Drop these GLBs in that folder (from the Grok zips):
- crimson_world_places.glb
- crimson_cosmos_sky.glb
- crimson_dragon_textured.glb
- dragon_palace.glb (backup if the world file is missing)

The game still runs without them. You get boxes instead of the art.

## 4. Play

Press the Play triangle.

- Arrow keys move
- Enter attacks
- Walk to the gold throne to wake the dragon

## 5. Export a Windows game later

Project → Export → Add Windows Desktop → download export templates when Godot asks → Export Project.
